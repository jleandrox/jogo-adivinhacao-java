# *JOGO DE ADIVINHAÇÃO.*

*Criei um Jogo de Adivinhação como primeiro projeto para meu GitHub, iniciando a trajetória em Java.
Consiste em um jogo onde você escolhe um número de "0 a 100", onde terá 10 tentativas para acertar o número secreto.
Caso informa um número fora do pedido, apresenta uma mensagem de erro.
Caso seu número seja maior ou menor do que o secreto, ele apresenta um dica dizendo se é "maior" ou "menor".
Se você perder as chances, o programa encerra informando qual número era, caso você acerte, ele finaliza o programa e parabeniza.*


**Detalhe: o programa está projetado para informar o número secreto no console, para fins de teste e aprendizado.**
