## 📌┃SOBRE O PROJETO

Este projeto marca o início da minha jornada com a linguagem **Java**.  
Desenvolvi um jogo de adivinhação interativo, onde o jogador deve descobrir um número secreto gerado aleatoriamente entre **0 e 100**.

O jogo foi projetado com foco em lógica de programação, validação de dados e interação via console.

---

## 🕹️┃COMO FUNCIONA

➤ O sistema gera um número entre **0 e 100**  
➤ Você possui **10 tentativas** para acertar  
➤ A cada tentativa, o sistema fornece dicas:


⬆️ O número é MAIOR
⬇️ O número é MENOR


➤ Caso digite um valor inválido:


⚠️ Número fora do intervalo permitido!
